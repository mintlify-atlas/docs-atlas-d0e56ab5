Backtest Index Fund is a research-grade backtesting project built on [backtest-kit](https://github.com/tripolskypetr/backtest-kit). Each month is a self-contained folder: $1,000 split equally across the top-20 Binance USDT spot pairs by prior-month volume, with market exposure scaled by a Bitcoin trend gate and the remainder parked in tokenized gold (PAXG). Positions are held for exactly one week and reopened at the next tick — 73 months replayed from September 2020 through September 2026.

## How It Works

<Steps>
  <Step title="Build the universe">
    Run `build_universe.mjs` to rank all Binance USDT spot pairs by prior-month volume and write `universe.json`. Resolve and verify Yahoo Finance ticker mappings so every basket symbol has a valid price series.
  </Step>
  <Step title="Generate month folders">
    Run `generate_months.mjs` to stamp 73 self-contained `content/<mon>_<yyyy>/` folders from the reference month. Each folder gets its own basket, ticker overrides, and frame — no shared code between months.
  </Step>
  <Step title="Run the backtests">
    Run a single month with `npm start -- --backtest --entry ./content/sep_2020/main.strategy.ts`, or run all months in sequence with `bash scripts/linux/generate_strategy.sh`.
  </Step>
  <Step title="Summarize results">
    Run `node scripts/common/summarize_reports.mjs` to fold every month's `backtest.jsonl` into one P&L table with cumulative equity and drawdown.
  </Step>
</Steps>

## Key Design Principles

<CardGroup cols={2}>
  <Card title="No Survivorship Bias" icon="shield-check" href="/strategy/overview">
    Each month's basket is frozen from data known before that month started. Delisted coins appear in their active months; this year's memecoins are absent from 2021.
  </Card>
  <Card title="Ensemble Gate" icon="sliders" href="/strategy/gate">
    Six lookback windows (20–45 days) vote on BTC momentum. A single lookback is a knife-edge parameter; an ensemble across a plateau is not.
  </Card>
  <Card title="Gold Counter-Position" icon="coins" href="/strategy/allocation">
    The fraction of the deposit not in the basket buys PAXG for the same week. The deposit is never idle — it moves between crypto and gold, not crypto and cash.
  </Card>
  <Card title="Copy-Paste Over Abstraction" icon="copy" href="/advanced/design-rules">
    Months are stamped, not imported. A refactor cannot change the result of a month that already ran. Each folder is independently reproducible.
  </Card>
</CardGroup>
